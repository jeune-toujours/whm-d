# WHM D — клиентский демо-контур

Кликабельный клиентский фронтенд WHM для просмотра экранов и сценариев до подключения бэкенда. В репозитории нет кабинетов сотрудников, администратора и серверной части.

## Запуск

Требуется Node.js 24 или совместимая версия.

```bash
npm ci
npm run dev
```

Откройте адрес Vite из терминала. Для сборки и проверки:

```bash
npm run build
npm run test:flows
```

Браузерные проверки используют установленный Google Chrome. При другом пути задайте `CHROME_PATH`. Чтобы проверить опубликованный контур, задайте `WHM_BASE_URL`.

## Просмотр

- `/#/home` — главный экран клиента.
- `/#/preview` — карта всех клиентских экранов, переключение сценариев «с вещами» / «первый вход» и этапов активного заказа.
- Верхняя панель «Все экраны» доступна на любом экране.
- Созданные в демо заказы, обращения и изменения профиля сохраняются только в `localStorage` текущего браузера. Переключение сценария сбрасывает демо-данные.

Любой четырёхзначный код, кроме `0000`, проходит демонстрационную проверку OTP. SMS не отправляется. Оплата и привязка карты имитируются без ввода реквизитов и списаний.

## Устройство и границы

Восемь исходных автономных экранов Svelte 5 подключены через [`src/App.svelte`](src/App.svelte). Карточка вещи, управление подпиской, история платежей и карта просмотра добавлены в `src/screens`. Общие демо-данные и операции находятся в [`src/demo.js`](src/demo.js). Маршруты используют hash URL, поэтому статическая сборка работает на Vercel без серверных rewrite-правил.

Описание решений, источников и следующего этапа: [`docs/client-preview.md`](docs/client-preview.md).
