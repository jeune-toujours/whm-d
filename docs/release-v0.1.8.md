# WHM MVP v0.1.8

Сохраняет изменения v0.1.7: ручной адрес курьера, нормализацию телефона, причину закрытия обращения и фото пломбы с приватным доступом владельца.

Полная проверка staging выявила гонку в истории: при переходе из возврата к связанной сдаче экран менял выбор до обновления URL. Старая ссылка могла снова выбрать возврат во время загрузки сдачи. Переход теперь синхронизирует URL сразу; завершившийся старый запрос не меняет актуальный экран и его ошибку.

Регрессия проверяется браузером с задержкой ответа деталей на 450 мс, фильтром «Возврат» и кнопками Back/Forward. Изменений схемы БД нет; используется миграция фото пломбы из v0.1.7.
